# Porting notes: Nordleaf design → Astro

Порівняння оригіналу (`.agents/propose/nordleaf.design/Main.dc.html`, віддається через `python3 -m http.server`) і порту (production-збірка під `wrangler dev`) на 375, 768 і 1280 px. Знімки робилися Playwright (full page, після прокрутки всієї сторінки, щоб спрацювали reveal-ефекти). Скрипти знімків одноразові й у репозиторій не входять.

## Мережевий лог

| Сторінка | Хости |
| --- | --- |
| Оригінал | сам сайт, `fonts.googleapis.com`, `fonts.gstatic.com` (+ react з `vendor/`) |
| Порт | лише сам сайт; `challenges.cloudflare.com` з'являється, тільки коли форма потрапляє у видиму область або отримує фокус. Cloudflare Web Analytics додається лише якщо задано `CF_ANALYTICS_TOKEN`. |

CDN, Google Fonts, unpkg/esm.sh та інші сторонні домени відсутні.

## Відхилення від дизайну

| Що | Оригінал | Порт | Причина |
| --- | --- | --- | --- |
| Заголовок hero | слова злиті («Zieleńdobranado Twojegownętrza»): між `inline-block` span не було пробілів | слова розділені пробілами | помилка прототипу |
| Фото | одне фото з 11 «кропами» через `background-position` | 13 нейтральних плейсхолдерів (11 карток + hero + band) з тими самими пропорціями | вимога ТЗ: справжні фото надасть клієнтка; фото з `assets/` не копіюємо |
| Зображення | CSS `background-image` | `<Picture/>` (AVIF + WebP), `<img>` з `alt` | ТЗ, пункт 6, доступність |
| Дропзона | до 4 файлів, HEIC | один слот, JPG/PNG/WebP до 5 МБ, прев'ю з видаленням | ТЗ (одне фото) |
| Поля форми | `imie`, `telefon`, `wiadomosc`, `zdjecia` | `name`, `phone`, `message`, `image` | контракт `POST /api/contact` |
| Контакти | `mailto:`/`tel:` на вигадані значення | клікабельні лише коли задано справжнє значення, плейсхолдер у дужках лишається текстом | плейсхолдери не мають вести нікуди |
| Вкладки | перерендер React, одна група в DOM | усі три групи в HTML, перемикання `hidden`; без JS — групи списком | SEO, деградація без JS |
| Hover-ефекти карток/кнопок | React-обробники | той самий розрахунок у vanilla (`src/scripts/effects.ts`) | немає React-рантайму |
| Фокус | лише браузерний за замовчуванням, `outline:none` у полях | додано `:focus-visible` (контур) | прохід доступності; вигляд мишею не змінено |
| «Nordleaf» у футері | літерні `.sw` у `.big-word.split` | те саме: літерні спани на збірці в `Footer.astro`, `aria-hidden` на контейнері | рішення з `::before` не знадобилося: axe лишається на 0 порушень |
| Фото «O Nordleaf» | `.crop` з `background-position` | `<Picture/>` у `.about-ph.rv-clip`, плейсхолдер `src/assets/placeholders/about.jpg` (кроп hero, 4:3); поля `image`/`imageAlt` у CMS | ТЗ: справжнє фото надасть клієнтка |
| Split-заголовки | розбиття на спани в розмітці | на збірці (`SplitHeading.astro` + `splitWords`), `aria-label` з повним текстом на `h2` | доступність і SEO |
| Reveal `.rv-clip` | IO дивиться на сам елемент | IO дивиться на батька (`.about-img`) і додає `in` до `.rv-clip` | `clip-path` схлопує сам елемент до нульової висоти, IO його не бачить |
| Preloader під reduced-motion | не вимкнений явно | `.pre{display:none}` | глобальне правило не обнуляє `animation-delay`, заставка висіла б ~2 с |
| LCP | — | 2,7–2,8 с (було 2,3–2,4 с) | заставка 2,2 с і пізніший старт hero за дизайном; поріг у специфікації послаблено до 3,0 с за рішенням розробника |
| Мобільне меню | завжди у DOM | `inert`, поки закрите, `aria-expanded` на бургері | клавіатурна доступність |
| `prefers-reduced-motion` | лише CSS | CSS + вимкнені паралакс, tilt, «магніт» у JS | доступність, залишено з дизайну й посилено |
| Без JS | порожня сторінка (React) | контент видно; `.rv`-reveal і вкладки вимагають JS, тому до його запуску блоки reveal прозорі | прогресивне покращення «наскільки можливо» |

Не повністю виконується: **форма без JS** працює як plain POST і повертає читабельну HTML-сторінку, але Turnstile без JS не може видати токен, тож такий запит відхиляється (403) з поясненням. Це обмеження Turnstile, а не реалізації.

CMS: плейсхолдери лежать у `src/assets/placeholders/`, а Decap шукає вже вибрані зображення у `src/assets/uploads/`, тому прев'ю плейсхолдерів у `/admin` не показується (у логах 404). Після заміни фото клієнткою файли лягають в `uploads/` і проблема зникає.

## Верифікація

- Висота повної сторінки: оригінал/порт — 375 px: 7988/8105, 768 px: 7306/7396, 1280 px: 5948/6032. На 1280 px секції збігаються по висоті, крім контактної (+11 px: плейсхолдерна форма); решта різниці — поза секціями й у переносах тексту на вузьких екранах.
- axe (`@axe-core/playwright`) на 375 і 1280: 0 порушень; прохід Tab іде логічно (шапка → hero → вкладки → «Zapytaj» → форма → футер).
- Ефекти (прогрес, паралакс, лінія кроків, reveal, tilt, магніт, pill, вкладки, меню, prefill) перенесені 1:1 з `tick()`/обробників оригіналу; бандл усіх скриптів ≈ 3,2 КБ gzip (ефекти ≈ 1,7 КБ + форма).
